relative gap \gapfrac', at constant locality; the spectral gap \specgap of the output
Hamiltonian is not claimed to change.

Every tracked symbol used here is a blessed macro with a register entry, so the sentence
says which quantity it means. The source's own spectral-gap token appears in this repo only
inside the register's translation row and its quote anchor (see
`definitions/notation/sym-specgap.md`) — quoted source notation, never campaign usage. This
line deliberately does NOT write that token: prose in a shard body is campaign usage, and
