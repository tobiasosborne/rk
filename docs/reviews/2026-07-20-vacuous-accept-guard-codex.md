## LANDING-BLOCKERS

1. **BLOCKER — `isProoflessNode` conflates missing proof with legitimate terminal assumptions, making valid af proofs unable to close.** The predicate treats `inference === "assumption"` as no justification ([`src/drive/driver-plan.ts:126`](/home/tobiasosborne/Projects/rk/src/drive/driver-plan.ts:126)), but af defines that inference as a real “global hypothesis” rule ([`internal/schema/inference.go:88`](/home/tobiasosborne/Projects/vibefeld/internal/schema/inference.go:88)). Af has no distinct axiom/global-assumption node type ([`internal/schema/nodetype.go:12`](/home/tobiasosborne/Projects/vibefeld/internal/schema/nodetype.go:12)); legitimate premises can therefore be `type:"claim", inference:"assumption"`. The live af tutorial explicitly shows and accepts exactly such a childless node ([`docs/tutorial-sqrt2.md:271`](/home/tobiasosborne/Projects/vibefeld/docs/tutorial-sqrt2.md:271), [`docs/tutorial-sqrt2.md:282`](/home/tobiasosborne/Projects/vibefeld/docs/tutorial-sqrt2.md:282)). AISM also terminates at validated leaves having that exact shape: node `1.1.1` is a childless, dependency-free `claim/assumption` proof step ([`000009.json:1`](/home/tobiasosborne/Projects/almost-idempotent-stochastic-maps/proofs/lem-classical-equiv/ledger/000009.json:1)) and was validated ([`000020.json:1`](/home/tobiasosborne/Projects/almost-idempotent-stochastic-maps/proofs/lem-classical-equiv/ledger/000020.json:1)). Definitions using `by_definition` are exempt, but global hypotheses and context-backed assumptions/externals are not: af stores those references in `Context` ([`internal/node/node.go:44`](/home/tobiasosborne/Projects/vibefeld/internal/node/node.go:44)), while graph export exposes only node dependencies ([`internal/export/graph.go:99`](/home/tobiasosborne/Projects/vibefeld/internal/export/graph.go:99)). Once such a leaf’s accept is discarded, its parent never becomes bottom-up ready because af requires every child to clear ([`internal/jobs/verifier.go:71`](/home/tobiasosborne/Projects/vibefeld/internal/jobs/verifier.go:71), [`internal/jobs/verifier.go:95`](/home/tobiasosborne/Projects/vibefeld/internal/jobs/verifier.go:95)).

   **Concrete fix:** do not classify arbitrary non-root `assumption` leaves as proofless. For this focused bootstrap incident, thread af’s existing `type` field and restrict the guard to the fresh root shape:

   ```ts
   n.id === "1" &&
   n.type === "claim" &&
   inference === "assumption" &&
   noChildren &&
   noDeps
   ```

   Add regressions for the tutorial/AISM terminal-assumption shapes. General child detection cannot safely use the current inference value because omitted justifications are defaulted to the same `"assumption"` value ([`cmd/af/record_proof.go:109`](/home/tobiasosborne/Projects/vibefeld/cmd/af/record_proof.go:109)). It requires af to record an unambiguous origin such as `conjecture | premise | prover_step` or `justification_origin: explicit | defaulted`; then exempt explicit premises/axioms and context-backed external facts.
