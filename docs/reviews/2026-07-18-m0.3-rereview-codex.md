## Ratification rulings

- **(a) RATIFY the stated semantics:** tracked stale ⇒ ERROR; untracked-but-present stale ⇒ ERROR with `[rk-stricter-intended]`; genuinely absent ⇒ WARN. This is the validity-safe ordering described at [gate-contracts.md:743](/home/tobiasosborne/Projects/rk/docs/gate-contracts.md:743). Current implementation does not fully realize it because “no hash fact” conflates absence with present-but-unloaded content ([provenance-checks.ts:44](/home/tobiasosborne/Projects/rk/src/gates/provenance-checks.ts:44)).

- **(b) RATIFY one aggregate WARN for frontmatter-invalid provenance exclusions.** Gate 2 owns the schema-validity ERROR, all six gates run unconditionally ([gate-contracts.md:85](/home/tobiasosborne/Projects/rk/docs/gate-contracts.md:85)), and the aggregate WARN names every excluded path while preserving an honest denominator ([provenance-parse.ts:88](/home/tobiasosborne/Projects/rk/src/gates/provenance-parse.ts:88)). The missing corpus exercise remains a separate L2 failure.

- **(c) RATIFY “fully conforming” as the shards numerator.** The unit now states its meaning, and cross-file failures correctly exclude affected shard identities ([gate-contracts.md:1069](/home/tobiasosborne/Projects/rk/docs/gate-contracts.md:1069)). This does not ratify the invalid-include denominator omission in NEW finding 3.

- **(d) RATIFY the missing-kind convention.** `kind` is required ([gate-contracts.md:300](/home/tobiasosborne/Projects/rk/docs/gate-contracts.md:300)); absent and empty values therefore warrant ERROR, and continuing other checks is preferable to excluding an otherwise identifiable shard ([linker-parse.ts:125](/home/tobiasosborne/Projects/rk/src/gates/linker-parse.ts:125)). The divergence is `rk-stricter-intended`, because AISM checks the enum only when `kind` is truthy ([argument.py:139](/home/tobiasosborne/Projects/almost-idempotent-stochastic-maps/scripts/argument.py:139)).

- **(e) RATIFY narrowly as exact effective-configuration equality.** Comparing all resolved `GateConfig` values prevents a hidden nondefault boundary ([corpus-run.ts:88](/home/tobiasosborne/Projects/rk/src/gates/corpus-run.ts:88)). It does not prove literal file presence: an undeclared `{}` or explicit-default file resolves identically to no file because the loader returns merged defaults in both cases ([config-load.ts:10](/home/tobiasosborne/Projects/rk/src/gates/config-load.ts:10)). The documentation’s “both directions” claim is therefore stronger than the implemented rule ([corpus/README.md:174](/home/tobiasosborne/Projects/rk/corpus/README.md:174)).

- **(f) OVERTURN the v2 flood attribution.** Collapsing identifiers by message template does not establish one causal root ([aism-divergence-triage-v2.md:144](/home/tobiasosborne/Projects/rk/docs/reviews/2026-07-18-aism-divergence-triage-v2.md:144)). Each WARN corresponds to a distinct shard independently satisfying the unanchored predicate, and each whitelist entry is independently deliberate ([UNWIRED.md:9](/home/tobiasosborne/Projects/almost-idempotent-stochastic-maps/report/UNWIRED.md:9)). The 96- and 118-warning historical buckets therefore exceed the explicit threshold without the contract’s single-root-cause exception ([gate-contracts.md:446](/home/tobiasosborne/Projects/rk/docs/gate-contracts.md:446)).
