# BRIEF

**Mode.** formalise | explore
**Question.** One sentence. For formalise: which paper, which results. For explore: the
conjecture or idea, stated as a claim.
**Scope / non-goals.** What is deliberately out.
**Done criteria.** Checkable: e.g. "thm-main is proved, refuted, or reduced to a named open
problem with a dead-routes ledger"; "every cited fact byte-verified"; "report 10-30 pages,
`make check` and `make build` green, one hostile audit + one repair wave done".
**Budget.** Waves: N. Agents per wave: ≤ M. Wall-clock: H hours. Families: author = claude,
verifier = codex (or `single-family` if unavailable).
**Ground truth.** arXiv ids / files to acquire under `sources/`.
**Known hazards.** Prior dead routes, notorious sign conventions, results known to be subtle.
